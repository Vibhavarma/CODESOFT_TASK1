# Titanic_Survival_prediction

## Project Overview
This project predicts whether a passenger survived the Titanic disaster using Machine Learning.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Data Preprocessing
- Handled missing values in Age and Embarked
- Removed Cabin column because of many missing values
- Converted categorical values into numerical values
- Removed unnecessary columns

## Machine Learning Model
Logistic Regression

## Model Accuracy
The model achieved approximately *79.9% accuracy* on the test dataset.

## Visualizations
- Confusion Matrix
- Survival by Gender
- Survival by Passenger Class

## Conclusion
The Logistic Regression model successfully predicts Titanic passenger survival with approximately 79.9% accuracy. Gender and passenger class are useful features for survival prediction.
